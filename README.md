# Mi Plan

Aplicación de estudio de inglés y soporte técnico N1. Incluye una agenda diaria, evaluaciones, repaso espaciado, bitácora y proyectos prácticos.

## Desarrollo local

Desde la raíz, ejecutá `python -m http.server 8000` y abrí http://localhost:8000. El frontend es estático y usa Supabase para autenticar y guardar el progreso por usuario.

## Portfolio

En IT → Prácticas y portfolio están las consignas y los criterios de entrega. El diagnóstico de Windows está en `portfolio/diagnostico.ps1`.
